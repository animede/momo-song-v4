# Security

Do not report credentials or private service addresses in public issues.

Before publishing a vulnerability-reporting address, repository owners should configure GitHub's
private vulnerability reporting or add a dedicated security contact here.

Momo Song binds to `127.0.0.1` by default. Exposing it to a network requires an authenticated reverse
proxy and is not a supported secure deployment by default. Generated media and prompts should be
treated as user data and must not be committed to the repository.
